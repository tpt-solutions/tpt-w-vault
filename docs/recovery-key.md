# Your recovery code

Your recovery code is a second way into your vault. Use it if you forget your passphrase.

## What it looks like

A row of 55 letters and digits, grouped with hyphens. You can type it with or without the hyphens.
Letters are not case-sensitive.

## When you see it

- Right after you create a vault. It is shown **once**. The app does not keep a copy.
- After you choose **Recovery code** in Settings. The old code stops working at once.

## Keeping it safe

- Write it down, or print it, and keep it somewhere that is not on the computer that holds the
  vault. A copy on the same disk is lost with the disk.
- Do not store it in a file next to the vault, or in a note inside the vault.
- Anyone with the code and the vault folder can open the vault. Treat it like your passphrase.

## Using it

1. On the unlock screen, choose **Recovery code**.
2. Enter the vault folder and the code.
3. Choose **Unlock**. Then set a new passphrase in **Settings → Passphrase**, since the old one
   may be the one you forgot.

## If you lose both

The vault cannot be opened. Nothing in tpt-vault can recover it, by design. Keep the code safe.
